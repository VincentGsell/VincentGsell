## About me

- 🧑‍💼 Tech lead at [Grid System](https://grids.systems/), where I design and build cross-platform software.
- ⚔️ Rust and modern Pascal are my shield and blade: one for control, the other for power. From 3D frameworks to simulation and servers.
- 🐍 Python for tooling and scripts, C and C++ when a library asks for it.
- 🎮 Interested in real-time graphics, physics, fast back ends, emulation and retro hardware, and IoT on the Raspberry Pi.

## Currently: [RetroLab](https://github.com/VincentGsell/RetroLab)

An arcade emulator written in modern Object Pascal. Seven games run on it today, from Capcom's 1942 to Sega's OutRun and Power Drift, played with a gamepad.
